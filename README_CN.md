# AI 意图技能

两个技能，让 AI 在行动前先搞清楚你想要什么。

---

## 解决什么问题

你说 **"我想买股票"**，AI 可能理解成：
- 教我基础知识
- 推荐具体股票
- 帮我开户
- 判断现在是不是好时机
- 分析这个想法是否靠谱

**猜错了，整个对话就偏了。**

你说 **"我想做 AI 电商"**，AI 可能马上给你方案，但：
- 不解释*为什么*某些方向可行
- 不告诉你*什么时候*建议会失效
- 不区分事实和猜测
- 不告诉你怎么快速验证

**学几个月才发现根本不可行。**

---

## 两个技能

### 意图澄清
回答前先搞清楚你到底想干什么。

- 列出 2-4 个可能的理解
- 展示每个理解的依据
- 问*一个*关键问题确认方向
- 形成"暂定目标"，你随时可以纠正

**何时用：** 请求模糊、有多种理解、高风险决策。

[查看技能 →](skills/intent-clarification-codex.md)

### 因果分析
拆解"什么决定成败"并深度解释。

- 识别决定性因素（真正会改变结果的）
- 解释*为什么*和*如何影响*，不只是*是什么*
- 用具体例子让你能想象实际场景
- 标注什么是事实 vs 假设 vs 未知
- 告诉你*什么时候*建议会失效
- 给你最小化验证方案

**何时用：** 目标明确但不懂领域，需要评估可行性，做商业决策。

[查看技能 →](skills/causal-factor-analysis-codex.md)

---

## 为什么分成两个

**不同的工作，不同的触发时机。**

| 意图澄清 | 因果分析 |
|---------|---------|
| 触发：说话模糊或有歧义 | 触发：目标明确但不懂领域 |
| 输出：确认后的暂定目标 | 输出：深度因果拆解 + 验证方案 |
| 深度：刚好能确认方向 | 深度：决定性因素的完整解释 |

合在一起会让两个都半生不熟。分开后各自做好自己的事。

---

## 它们如何配合

```
你："我想买股票"
    ↓
意图澄清：
  "我想到 4 种可能... 哪一种？"
    ↓
你："我想先学习，然后买一点试试"
    ↓
因果分析：
  "这些因素决定成败：
   - 市场选择（为什么：影响监管、成本...）
   - 风险承受（为什么：决定仓位大小...）
   - 开户流程（为什么：影响速度...）
   
   每个因素都包含：
   ✅ 已知什么
   ❓ 未知什么
   ⚠️ 假设什么
   🔄 什么情况下改变"
```

## 安装

### Codex
复制 `skills/intent-clarification-codex.md` 和 `skills/causal-factor-analysis-codex.md` 到你的 Codex 技能文件夹。

### Harness（桌面版）
复制文件到 `C:\Users\<你的用户名>\.dsh\skills\`，目录格式：

```
C:\Users\<你的用户名>\.dsh\skills\
├── intent-clarification\
│   └── SKILL.md
└── causal-factor-analysis\
    └── SKILL.md
```

安装后，AI 会根据输入自动加载对应的 skill。你也可以手动调用：
```
skill("intent-clarification")
skill("causal-factor-analysis")
```

详细安装说明见 [Harness 集成指南](docs/harness-integration.md)。

## 有什么不同

**vs. 普通追问**  
大多数 AI 只是问更多问题。这些技能*展示*给你 AI 是怎么理解你的话的，你可以早点纠正误解。

**vs. 标准任务拆解**  
标准拆解给你步骤。这个给你*因果关系*：为什么每个因素重要、如何影响结果、什么时候不重要。

**vs. 现有工具（Rasa, PMAgent, TypeChat 等）**  
研究了 6+ 个项目，没有一个做完整流程：
- **Rasa：** 有候选排序 + 置信度，但不让你选
- **PMAgent：** 有选项式提问，最接近，但只针对 PM 场景
- **TypeChat：** 有结构化确认，但没有概率排序
- **UAP：** 有不确定性采样，但不给用户展示候选

[查看完整对比 →](docs/comparison.md)

**我们的组合：** 候选排序（Rasa）+ 用户选择 + 因果解释 + 暂定目标 + 反转条件

## 真实测试

**股票投资场景：** "我想从零学会怎么买股票" → 列出 4 种理解 → 确认既想学也想买 → 拆解市场选择/风险承受/开户流程 → 一次对话从模糊想法到清晰路径（9.0/10）

**Agent 配置场景：** "感觉我需要规范化 agent 用法" → 列出 4 种可能 → 深入拆解 agent 机制/工作文件夹/交接技能 → 用户从"完全不懂"到完全理解（9.66/10）
